🗄️  DATABASE SCHEMA:
───────────────────────────────────────────────────────────────

Table: dishes
  • id (UUID, Primary Key)
  • name (Text) - Menu name
  • description (Text)
  • price (Integer) - In Rupiah
  • category (Text)
  • image_url (Text) - Photo URL
  • is_bestseller (Boolean)
  • is_available (Boolean)
  • created_at (Timestamp)
  • updated_at (Timestamp)

Table: settings
  • id (Text, Primary Key = '1')
  • whatsapp_number (Text)
  • updated_at (Timestamp)

Storage: dishes bucket
  • Public images storage
  • For product photos
